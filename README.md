# Заказ в интернет-м
ФИО: Плохих Никита Александрович
Группа: Б9124-02.03.01сцт

## Предметная область

Приложение моделирует один заказ интернет-магазина. У заказа есть статус (оформляется, оплачен, в пути, доставлен, отменён, возвращён) и свойства: количество товаров, наличие адреса, оплаченная сумма и число дней, оставшихся на возврат.

## Правила

- Состав заказа (+/− товар) меняется только пока заказ оформляется, адрес — до отправки.
- Оплатить можно только оформляемый заказ с указанным адресом и суммой не менее 1000 ₽.
- Отправить можно оплаченный заказ, если адрес указан (его можно стереть уже после оплаты).
- Отменить можно только оформляемый или оплаченный заказ (оплаченная сумма возвращается); отправленный отменить нельзя.
- После получения у заказа есть 3 дня на возврат; кнопка «Прошёл день» уменьшает срок, а когда он истёк, возврат недоступен.
- Отменённый, возвращённый и просроченный для возврата заказ выделяется цветом и предупреждением; блок состава и адреса блокируется после отправки.
- Кнопка «Сбросить» возвращает заказ в исходное состояние.

Состояние хранится через rememberSaveable и переживает поворот экрана.
